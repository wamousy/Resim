# Resim 页面组织

页面以两项任务为中心：识别当前架构实现难点，辅助 partition 和 floorplan 规划。

## 工作区

| 页面 | 使用目的 |
| --- | --- |
| 架构输入 | 分别导入架构/工艺库 YAML，或网页定义 Die、模块与连接；输出目录与校验 |
| 布局规划 | 整体/单核、层视图、模块选择、坐标编辑与跨层移动 |
| 连接与布线 | 检索连接、查看位宽、带宽和金属资源 |
| 资源与计算 | 各层资源总览 → 单层分类明细 → 按需查看公式与参数口径 |
| 实现难点 | 根据资源计算结果呈现违例、风险和待补数据，查看对象与建议，返回布局定位 |
| 结果管理 | 命名批次及方案，保存当前/选中/全部候选，查看历史报告，跨批次/方案/工程比较 |

固定导航维持页面切换。工程载入、新建、命名及项目文件夹选择只在架构输入页；当前方案、候选数量与自动分区布局只在布局页。保存评估结果仅出现在结果管理，可填写结果名称。选中对象后，画布与对象详情以 1:1 等宽、等高排列，详情独立滚动；窄屏改为等宽上下排列。模块编辑、显示选项、尺寸明细按需展开。专注视图隐藏外围控件，Esc 返回。

网页切换不提交输入、不重新模拟，也不丢弃当前草稿。资源计算仍使用完整输入快照；独立架构与工艺库 YAML 在预览前合并，详见 INPUT-WORKFLOW.md。

## 当前前端文件

前端源码统一在 `src/frontend/` 编辑。`index.html` 定义页面，`studio.css` 定义工作台布局，`workbench.js` 负责导航，`app.js` 连接现有评估数据。修改后从 Resim 目录执行 `node src/tools/sync-web.mjs`，发布到 `app/_internal/resim/static/`；运行中的程序提供发布副本，刷新页面即可载入更新。完整验收会检查两个目录逐文件一致。

input-editor.js / architecture-io.js 负责双输入入口与两文件格式；multi-comparison.js 负责按需读取、选择和并列比较历史结果，layout-variants.js 按实际模块布局识别不同方案。

Die ID 支持唯一性校验与引用同步重命名；宽、高可直接输入并联动面积。默认说明保持简短，工艺依据、寻优方法等详细解释按需展开。页面已删除“芯片资源实验室”页脚。

“定义项目”使用原生折叠栏目，展开/收起不丢失内容。下拉框仅列真实已有项目，不含“选择已有项目”；无项目时显示禁用空状态。点击“新建项目”才显示名称及位置填写项，“收起”保留草稿。项目名称是显示名称；“项目保存位置”是独立选择的完整文件夹路径，明确提示不会按项目名称再建目录。载入项目或首次保存后结束创建状态。结果目录使用项目 / 批次 / 方案，网页不再写 runs 和 _batch-index 重复索引。

“打开项目文件夹”与新建操作分开，复用目录选择对话框。打开模式隐藏“新建文件夹”，确认按钮为“打开此项目”；选择错误时保留对话框并显示原因。项目列表通过 project.json 自动扫描默认目录，选项提示显示实际位置；外部项目仅在当前运行期间加入列表，重启后重新打开，不额外生成登记目录或项目索引文件。

布局新增可点击的堆叠关系条、单层正面/背面观察。对象详情默认收起，选择模块、Die、接口或连线时展开；约束检查按需打开。朝向及接口约定见 [STACK-MODEL.md](STACK-MODEL.md)。

查看范围、显示层与显示选项现位于画布顶部，专注视图中也可切换。点击 Core 先显示各层布局尺寸、整片尺寸与跨 Core 接口，再通过“查看核内布局”进入细节；点击 Die 查看该层尺寸和芯片各层尺寸。跨 Core 接口可显示完整连接路径。

点击模块才显示位置编辑：所在 Die、X/Y 坐标和应用修改；吸附与外围预留折叠。拖动仅作用于选中模块，平移和旋转会退出模块拖动。撤销/重做在画布工具栏，全局模块间距在架构输入的“布局约束”。移动后的指标对比在资源与计算的“当前预览变化”。

布局默认按模块类型显示，保留 BLX 示例的功能区配色，移除诊断着色和线束占宽叠加；拥塞、利用率、功耗和金属面积计算仍在资源与计算及对象资源明细中。原画布下方尺寸和外部接口区域、重复操作说明与模块下拉选择已删除。

架构输入按 01 定义项目、02 架构输入与布局约束、03 工艺库与连线资源组织。02/03 默认折叠，展开后分别选择“导入 YAML”或“自定义”，未选择时不显示表单。Die、模块、连接与间距约束可继续按需展开；完整输入快照放在 02 的高级入口。

工艺自定义支持金属层增删、名称/方向/线宽/pitch/可用比例，以及默认 TSV/键合参数；工艺来源和未在表单展示的校准参数会保留。字段校验后使用同一预览接口重新计算，应用不自动写入历史。

自动分区与布局接受正整数候选数量，不设固定个数上限。卡片单行横排，超出窗口时显示左右按钮和滑块；滑块只浏览列表，点击卡片才切换实际方案。卡片仅展示不同候选，标出模块位置和跨层迁移差异。“寻优前布局”是启动本次搜索时的输入布局，可通过下拉框回看，不计入候选数。候选按模块 ID、Die、坐标和尺寸识别，不依赖方案编号或求解分数。引擎排除已求得的坐标/Die 组合，页面再次去重并保留真实存储索引。到达请求数量、时间内数量不足、解空间已穷尽分别说明；仅穷尽时确认当前离散约束下的数量，不承诺全局最优。网页寻优不自动保存；到结果管理为选中的候选命名保存。

“连接与布线”只显示信号 TSV、拥塞和连接/布线数据，隐藏堆叠结构、总功耗与全局违例摘要。结果管理中的历史对比默认收起；可自由添加或移除对比位置，选择后点击开始，所有方案平等并列。模块差异和问题明细按需展开，移除单独的基线对比区域。

实现难点已移除重复的“05 实现性评估”引导条及其两个快捷按钮，保留实际问题、原因、建议和问题对象定位。

实现性违例、风险与提示、待补数据均为可点击卡片。详情默认收起，点击分类展开，重复点击或点击“收起”关闭。每项保留各自的对象、原因和建议，30 项一页，定位使用完整问题索引，避免合并同类问题时丢掉个体差异。零项分类显示明确空状态。移除“模块互联”“资源总览”“计算依据”“运行记录”等重复辅助标题，保留有用的单位、计算依据和实际结果。

资源与计算不再平铺工艺说明、总表、金属层表、公式和供电表。首先展示简洁的各层总览，点击 Die 或切换统一选择器后，按“面积与利用率 / 布线与拥塞 / TSV 与 HB / 功耗与供电”查看同一层结果。模块、预留区、分层容量、通道、间距、公式、工艺依据默认折叠，长表独立滚动。抽象 DRAM 平台不展示内部面积和功耗；历史报告没有计算过程时明确提示。待重算时不显示旧结果作为当前结果。

跨层预算按相邻 Die、接口类型分组，并汇总全部 Core/MC 区域，未知分量不按零累加，HB 不计为 TSV。每组保留逐区域结果，避免合计余量掩盖局部不足。供电表和端口编辑同步过滤到选中的 Die。数据通路延迟估算移至连接与布线中的折叠项；重复导出按钮移除，资源报告与布局图集中在结果管理。
## 0.12 长表操作

资源与计算 → 布线与拥塞 → 模块间距支持模块 ID 搜索、通过/不足筛选、每页 25/50/100 条及上一页/下一页。统计仍覆盖全量记录，折叠时不渲染表格，展开时只渲染当前页。点击模块名称切到布局规划并定位其 Core 和 Die。

结果保存入口仅位于“结果管理”。表单包含“批次文件夹名称”和“当前方案名称”，默认操作为“保存当前方案”；候选批量保存区域默认折叠，展开后可勾选、改名并保存选中或全部候选。保存内容说明按需展开。批次首次保存后名称锁定，各方案平级放在批次内。同批次相同方案不重复保存，重名目录自动追加序号，历史列表按批次分组。批量保存显示逐方案进度，失败保留已完成项，可继续重试。输入待应用或预览未成功时禁用保存并说明原因。完整目录与快照内容见 INPUT-WORKFLOW.md。

布局页只生成候选预览。寻优时跨工作空间保留任务状态栏，显示不确定进度动画、真实耗时以及完成/失败结果；完成后可前往结果管理保存。

新批次内每方案统一保存独立 inputs、floorplan.svg、实现难点 Markdown、资源 HTML/JSON 和必要 run.json。结果区保留“打开结果文件夹”“复制路径”“查看布局图”和“资源报告”，删除额外的“下载 JSON”“下载布局 YAML”按钮。文件夹中的资源 JSON 和双 YAML 继续用于历史读取、比较和复现；兼容导出 API 保留，保存内容不变。
